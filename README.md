# K8S Playground
A hands-on local Kubernetes lab environment built with Minikube for testing, configuring, and deploying applications in a cloud-native ecosystem.

This project is designed as a practical playground to experiment with Kubernetes concepts locally without requiring a cloud provider or production infrastructure.

The first phase of the project focuses on deployment strategies, including:

Rolling Updates
Recreate Deployments
Blue-Green Deployments
Canary Releases

Additional topics planned for future stages include:

Helm charts
Ingress configuration
Observability and monitoring
CI/CD integrations
GitOps workflows
Scaling and resource management
Kubernetes networking and security

The goal of this repository is to provide a simple and reproducible environment for learning, experimentation, and DevOps practice using Kubernetes and Minikube.
